# ACCELA FIX

Alternative installer for Accela (present in [enter-the-wired](https://github.com/ciscosweater/enter-the-wired)) for users experiencing issues with the AppImage version `20260512222534`. Uses the Python source code from the stable version `20260425230142`.

> Accela authors unknown. Credits to the maintainer of enter-the-wired, [ciscosweater](https://github.com/ciscosweater).

## Install

```bash
git clone https://github.com/Cybercountry/ACCELA_FIX.git && cd ACCELA_FIX/ACCELA-20260425230142-linux && ./ACCELAINSTALL
```

## Uninstall

```bash
cd ACCELA_FIX/ACCELA-20260425230142-linux
./ACCELAUNINSTALL
```
